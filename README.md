# Colby

Monitor Combustion thermometers from your computer.

- `web/`: browser version (Chrome or Edge), live at https://colbyapp.github.io/. It deploys only from a `web-vX.Y.Z`
  tag, not on merge; see "Ship a release" in `web/README.md`.
- `mac/`: macOS app
- `windows/`: Windows port
- `docs/`: plans and protocol notes. Logo source art is in `docs/design/logo/`.

Not affiliated with Combustion Inc.
